🌦️ Smart Weather Dashboard

📌 About the Project

An AI-powered Smart Weather Dashboard built using Python, Flask, HTML, CSS, and JavaScript. It provides real-time weather information, weather forecasting, and smart weather insights.

🚀 Features

* Real-time weather updates
* Weather forecasting
* Smart weather insights
* User-friendly interface
* Dynamic weather information

🛠️ Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript

📂 Project Structure

smart-weather-dashboard/
│
├── app.py
├── weather_model.py
├── static/
│   ├── script.js
│   └── style.css
└── templates/
    └── index.html

▶️ How to Run

1. Clone the repository.
2. Install the required dependencies:
    pip install flask
3. Run the application:
    python app.py
4. Open your browser and visit:
    http://127.0.0.1:5000
